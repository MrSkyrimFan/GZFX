GZFX 0.0.31 SKSE SINGLE-DLL MIGRATION — RESEARCH
Date: 2026-11-04

TARGET RUNTIME
- Current released Steam Anniversary Edition runtime: Skyrim 1.7.104.
- Current released SKSE build for that runtime: SKSE 2.3.1, release index 75.
- GZFX 0.0.31 will initially declare exact compatibility with 1.7.104. Broader runtime compatibility is a later field-proven task, not an assumption.

SKSE PLUGIN ABI
The official SKSE plugin interface provides:
- SKSEPlugin_Preload and SKSEPlugin_Load entry points;
- runtime/SKSE version information;
- plugin handles;
- Messaging interface and game lifecycle messages;
- Task/Scaleform/Serialization/Object interfaces;
- Trampoline pools for native patch/hook work.

STARTUP ORDER
Current SKSE supports a preload phase before normal plugin Load and before normal game initialization. That gives GZFX an early point to arm its existing D3D11 import lifecycle probe without planting a local d3d11.dll beside SkyrimSE.exe.

DEPENDENCY / DISTRIBUTION DECISION
SKSE runtime binaries are NOT redistributed by GZFX. Users install official SKSE separately. GZFX only implements the public plugin ABI and ships GZFX.dll under Data/SKSE/Plugins/.

COMMONLIB DECISION
Current CommonLibSSE-NG 15.x is GPL-3.0-or-later. Static linking would impose GPL-compatible licensing requirements on the plugin. No CommonLib dependency is introduced in this migration. GZFX keeps its own D3D11 renderer, signatures, and bounded runtime logic while using the official SKSE plugin ABI directly. A future owner-approved licensing/architecture decision may revisit this.

HOOK OWNERSHIP
- D3D11/DXGI COM interception remains GZFX-owned and MinHook-based for this migration.
- SKSE Trampoline is acquired and retained for future executable integration.
- Existing 1.7.104 engine discovery remains discovery-only; this migration does not promote unverified engine hooks.

SECURITY / PACKAGING
Eliminating system-named local proxy DLLs removes the d3d11.dll/dinput8.dll proxy-forward-load pattern from the public package. This cannot guarantee zero antivirus false positives, but it materially simplifies the package and reduces suspicious loader behavior.

END RESEARCH
