======================================================================
7. SHARED RUNTIME
======================================================================

Runtime owns:

    device;
    one deferred context;
    fullscreen vertex shader;
    luminance/bloom pixel shader;
    exposure pixel shader;
    final product pixel shader;
    linear and point samplers;
    parameter constant buffer;
    sourceCopy + SRV;
    output + RTV;
    bloom/luminance pyramid + RTV mip 0 + SRV;
    exposure A/B textures + RTV/SRV;
    validated depth SRV;
    validated motion SRV;
    optional native normal/aux SRVs;
    GPU timing queries;
    width/height/format;
    history index/validity;
    resource generation;
    structural settings revision.

Allocation rules:

    scene must be single-sample;
    source/output use scene format;
    pyramid base is half resolution rounded up;
    pyramid has full mip chain;
    pyramid format R16G16B16A16_FLOAT;
    exposure history format R16G16_FLOAT or RGBA16F;
    failures release the whole partially created runtime;
    resize/device/format change rebuilds atomically.

======================================================================
8. SHADER / PASS GRAPH
======================================================================

Compile one HLSL source with entries:

    VSMain
    PSLuminanceBloom
    PSExposure
    PSComposite

Pass A — source snapshot:
    CopyResource MAIN_HDR -> sourceCopy

Pass B — luminance/bloom mip 0:
    render half-resolution from sourceCopy
    output:
        RGB = soft-knee bright contribution
        A = log luminance

Pass C — pyramid:
    GenerateMips on the shared pyramid

Pass D — exposure:
    render 1x1
    inputs:
        last pyramid mip
        previous exposure
    output:
        adapted exposure
        target exposure
        measured luminance
        validity
    ping-pong A/B

Pass E — final composite:
    full resolution
    inputs:
        sourceCopy
        depth
        motion if available
        pyramid
        current exposure
        optional native normal/aux
    output:
        final HDR scene

Pass F — one writeback:
    CopyResource output -> MAIN_HDR

No other recovered effect performs a separate full-resolution copy/writeback.

======================================================================
9. FINAL COMPOSITE ORDER
======================================================================

PSComposite order:

    sample/decode source;
    optional depth-aware denoise;
    optional motion gather;
    optional DoF gather;
    optional depth fog;
    add weighted bloom pyramid;
    modulate bloom with procedural lens dirt;
    apply manual/automatic exposure;
    apply temperature/tint;
    apply lift/gamma/gain;
    apply saturation/vibrance;
    apply contrast/gamma;
    apply toe/shoulder/white clip shaping;
    apply vignette;
    apply monochrome grain;
    apply radial chromatic aberration;
    apply high-pass sharpening;
    apply letterbox/pillarbox mask;
    return HDR color with original alpha.

Neutrality requirements:

    every disabled branch is exact identity;
    productEnabled=false returns source exactly;
    missing optional depth/motion inputs disable only dependent effects;
    NaN/Inf guards return finite clamped values;
    split development mode preserves left half original where required.
