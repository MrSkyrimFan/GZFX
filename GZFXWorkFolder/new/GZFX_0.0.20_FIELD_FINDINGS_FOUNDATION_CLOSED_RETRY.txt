======================================================================

The project spent several versions solving the difference between:

"a texture that looks plausible"

and:

"a resource whose meaning and execution boundary are safe enough for a
production renderer."

That work was necessary because earlier AO/SSIL prototypes proved that merely
having depth, HDR, normals and motion was not enough to produce stable,
correct integration.

However:

the foundation problem is now sufficiently solved.

Continuing the same broad cartography workflow from here WOULD be too slow.

The workflow should change.

28. NEXT RESEARCH SHOULD BE SHORT AND TARGETED
======================================================================

The next research phase should not reopen Skyrim's entire renderer.

Research only what Wave 3 needs immediately:

1. Best hierarchy format / mip strategy for GZFX-owned post-opaque depth.

2. Exact native motion-vector convention and reprojection sign/scale.

3. Temporal rejection strategy:
   - current vs previous depth
   - normal rejection
   - disocclusion
   - camera-cut detection
   - dynamic-resolution invalidation

4. How to create and bind the GZFX depth hierarchy at AfterOpaqueWorldMRT
   without corrupting Skyrim state.

5. Whether to build the hierarchy with graphics draws, compute, or a hybrid
   given D3D11 and the RTX 4060 Laptop reference system.

6. Diagnostic views needed to prove it in one compact field run.

That research should lead directly into a Wave 3 blueprint.
