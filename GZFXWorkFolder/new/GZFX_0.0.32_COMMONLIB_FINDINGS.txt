GZFX 0.0.32 COMMONLIB MIT ENGINE ACCESS — FINDINGS
Date: 2026-11-05

OWNER DIRECTIVE
Integrate CommonLib so GZFX can aggressively use Skyrim-native engine knowledge instead of relying only on raw SKSE and D3D11 inference.

CURRENT BASELINE
- GZFX 0.0.31 is an SKSE 2.3.1 native plugin for Steam Skyrim 1.7.104.
- Public package contains one GZFX binary at Data/SKSE/Plugins/GZFX.dll.
- GZFX-owned d3d11.dll and dinput8.dll proxies are retired.
- Existing renderer/semantic contracts remain field-locked and must not be replaced by unverified engine assumptions.

COMMONLIB DISCOVERY
1. alandtse/CommonLibSSE-NG current releases are GPL-3.0-or-later and unsuitable for a proprietary GZFX static link without a license-model change.
2. CharmedBaryon/CommonLibSSE-NG is MIT but stopped at v3.7.0 in 2023 and does not understand Skyrim 1.7.x correctly.
3. eddoursul/CommonLibSSE-GG is a current MIT continuation of the last permissive line.
4. CommonLibSSE-GG explicitly implements Skyrim 1.7.99 / 1.7.104 runtime classification, Address Library format 5, and known 1.7 layout changes.
5. Its README states it branches from the last MIT upstream commit and that no GPL-upstream code was copied.
6. Commit 3aa704ee2de9fdba3a2e77cc08e3d3ed8ea6e00f adds 1.7.104 support and verifies 1.7.104 as a recompile of 1.7.99 with no additional structure-layout change.
7. Current repository head 2053e94fd1c147b36eae2b4338118552fba407e2 retains that support and remains MIT.

ENGINE ACCESS OPPORTUNITIES
CommonLib can immediately give GZFX typed access to:
- REL runtime/module/version machinery;
- Address Library v5 relocations on 1.7.104;
- RE::BSGraphics::Renderer and renderer data;
- RE::Sky / TESWeather / climate / sun / moon / cloud state;
- RE::TESDataHandler and game-form databases;
- hundreds of additional RE types for later water, shadows, image-space, materials and scene systems.

CONSTRAINT
CommonLib knowledge must augment, not silently replace, field-proven GZFX renderer evidence. Any new engine-native pointer/layout used in production must be validated on 1.7.104.

END FINDINGS
