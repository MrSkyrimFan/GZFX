5. LANE C — PRIMARY RENDERER QUALIFICATION
======================================================================

Before GZFX_AttachPrimaryD3D11 is invoked from the d3d11 proxy, qualify the
candidate.

Normal product acceptance requires:

A. caller provenance

    call originated in the main executable module;

B. driver class

    reject:
        D3D_DRIVER_TYPE_WARP
        D3D_DRIVER_TYPE_REFERENCE
        D3D_DRIVER_TYPE_SOFTWARE
        D3D_DRIVER_TYPE_NULL

    allow:
        D3D_DRIVER_TYPE_HARDWARE
        D3D_DRIVER_TYPE_UNKNOWN when an explicit adapter is used and the actual
        adapter passes hardware checks;

C. adapter identity

    query the created device's IDXGIDevice/adapter;
    reject Microsoft Basic Render Driver:
        VendorId 0x1414
        DeviceId 0x008C;

D. swapchain window, when present

    if OutputWindow is non-null:
        require it belongs to current process.

Test-only override:

    GZFX_TEST_ALLOW_SOFTWARE_PRIMARY=1

permits WARP/reference software testing.

It must not be consulted/required in normal product runs.

Startup telemetry events:

    primary_candidate_accepted
    primary_candidate_rejected

with result/reason codes.

Do not permanently bind a rejected device.

7. LANE E — SAFE PROCESS-EXIT TELEMETRY CLOSURE
======================================================================

Remove runtime.cpp std::atexit telemetry Shutdown registration.

Install a process-level ExitProcess detour from the long-lived d3d11 bootstrap.

Bootstrap additions:

    static MinHook link;
    ExitProcessFn original;
    atomic exit-hook-installed;
    atomic shutdown-once guard.

Install hook lazily on first relevant D3D bootstrap use, outside DllMain.

Hook behavior:

    if first invocation:
        record process_exit_intercepted when possible;
        resolve/check GZFX module;
        if GZFX initialization state == ready:
            call exported GZFX_Shutdown();

    call original ExitProcess(exitCode);

Never return.

If GZFX is absent/not ready:

    call original ExitProcess immediately.

Do NOT:

    join threads from DllMain;
    call GZFX_Shutdown from DLL_PROCESS_DETACH;
    retain std::atexit as a competing second mechanism.
