GZFX 0.0.32 COMMONLIB MIT ENGINE ACCESS — BLUEPRINT
Date: 2026-11-05
Branch: feature/0.0.32-commonlib-mit-engine-access

OBJECTIVE
Add a current MIT CommonLib engine-access plane to the existing one-DLL GZFX SKSE architecture and use it immediately for typed Skyrim renderer/sky/data access without disturbing locked renderer semantics.

IMPLEMENTATION
1. Pin eddoursul/CommonLibSSE-GG commit 2053e94fd1c147b36eae2b4338118552fba407e2 through FetchContent.
2. Build CommonLib AE-only, no VR/SE, no CommonLib tests, no IPO.
3. Add vcpkg manifest dependencies and CI toolchain using x64-windows-static-md.
4. Upgrade GZFX compile baseline to C++23 to match current CommonLib.
5. Link CommonLibSSE::CommonLibSSE statically into GZFX.dll.
6. Add gzfx::engine::commonlib_bridge with:
   - module/version validation;
   - Address Library presence check;
   - DataLoaded binding to Renderer/Sky/TESDataHandler;
   - renderer-device/context/swapchain correlation;
   - bounded fallback AttachPrimaryRendererObjects only when valid;
   - thread-safe engine snapshot;
   - per-frame read-only Sky/weather refresh.
7. Call module initialization during SKSEPlugin_Load.
8. Call engine binding on SKSE DataLoaded.
9. Call per-frame snapshot refresh from the already-owned primary Present path.
10. Add diagnostics/commonlib_engine.txt with deterministic status and pointer correlation.
11. Add a compile-contract test proving the pinned CommonLib exposes 1.7.104 and selected engine types.
12. Keep CI harnesses non-Skyrim-safe by bypassing real CommonLib module/ID database access under GZFX_TEST_OUTPUT_ROOT.
13. Keep package file payload exactly Data/SKSE/Plugins/GZFX.dll.
14. Update install docs: SKSE 2.3.1 + Address Library for 1.7.104 required.
15. Preserve all existing 37 tests and add the CommonLib contract test.

NON-GOALS
- no graphics-quality feature implementation;
- no engine-state writes;
- no CommonLib-generated SKSE plugin entry point;
- no replacement of the existing GZFX SKSE bridge;
- no promotion of WaterDomain, PostTonemapPreUi, AfterShadowProduction;
- no weakening of existing HDR/TAA/semantic gates.

ACCEPTANCE
- build succeeds with pinned MIT CommonLib;
- package remains one GZFX DLL;
- existing 37 tests stay green;
- new CommonLib compile/runtime-contract test green;
- SKSE front-door harness remains green without Skyrim/Address Library present;
- no CommonLib DLL appears in package;
- PR green;
- merged-main green before field testing.

END BLUEPRINT
