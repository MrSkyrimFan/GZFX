CONTROL/PRESET RECOVERY
  - Add Reset Defaults action visibly near preset/custom rows.
  - Reset active state to safe Values{} and persist, preserve saved
    Custom1/2/3 profile sections and metadata.
  - Selecting a built-in look in the Preset slider applies its fields
    immediately. Retain ApplyPreset for explicitly reloading a look.
  - Built-in looks start from Values{}, never prior edited g_values.
    Preserve current quality tier and selected custom slot, not old art.
  - Shrink disastrous ranges across ambient, exposure, bloom, color,
    DoF, motion, fog, optics, filtering. Keep 0/neutral and fine steps.
    Migrate legacy INI by existing clamping on Reload.
  - Tone processing must protect hue/black; no unbounded shoulder
    crushing and no forced greyscale.
  - Every persisted slider update to exactly same value should be no-op,
    reducing drag/write churn.
  - Colorblind accessibility remains monochrome/text, not hue-dependent.

MODE CONTROL RECOVERY
  - Shift+Num3 toggles exactly 0=Vanilla vs 2=GZFX ON.
  - Startup default mode ON, legacy 1/3/4 default INI normalize to ON.
  - Startup mode slider only OFF / GZFX, no debug modes.
  - Menu and manual diagnostics remain independently usable.

SIX COHERENT NEW SCENE POST FEATURES (SAME HDR COMPOSITE)
  (1) Shadow recovery strength
  (2) Highlight rolloff strength
  (3) Luminance clarity/local contrast strength
  (4) Warm halation strength
  (5) Split toning: independent shadow & highlight warmth controls
  (6) Subtle pre-tonemap dither strength
  All default zero; conservative slider maxima; each has real HLSL effect,
  safe neutral path, live parameter, setting persistence, menu label and
  effect-mask/status visibility. No new full-resolution renderer, scheduler,
  GPU texture resource, temporal history or scene writeback.

HLSL / RESOURCE ORDER
  Shared bright-pyramid should be built when either bloom or halation
  needs it. Compute bright source once in composite and scale for bloom
  and halation; no duplicate 6-layer bloom scheduler.
  New effects inserted in one ordered post-tonal path:
    denoise/motion/DoF/ambient/fog -> bloom/local glow/halation
    -> exposure -> shadow recovery -> highlight rolloff
    -> ApplyColor -> split tone -> shared clarity -> tone shaping
    -> optional fine dither -> original optics and composition.
  Hue-preserving tone shoulder uses luminance ratio, maintains HDR.
  C++/HLSL cbuffer parameters 16-byte aligned, same order.
  BuildEffectMask bits must remain unique and never collide with
  AmbientContact/HBAO/Indirect/LocalGlow.
  Avoid unnecessary GPU samples when new feature sliders are zero.
