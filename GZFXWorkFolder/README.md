# GZFX Authority Workspace

This directory is the permanent repository-native engineering memory for GZFX.

- `new/` contains the current field cycle's active findings, research, and blueprint.
- `old/` contains completed cycles, historical authority, engineering result records, and superseded-but-preserved evidence.

Normal cycle:

```text
field evidence
-> findings TXT in new/
-> research TXT in new/
-> blueprint TXT in new/
-> implementation from repo
-> CI / PR / merge / package proof
-> engineering result TXT in old/
-> move completed three cycle TXT files new/ -> old/
-> clear new/
-> in-game instructions in chat
-> next field cycle
```

Do not ask the user to manually shuttle these authority files between ChatGPT and a local folder.

See root `AGENT.md` for the mandatory operating contract.
