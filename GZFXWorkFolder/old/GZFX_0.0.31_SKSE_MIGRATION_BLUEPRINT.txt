GZFX 0.0.31 SKSE SINGLE-DLL MIGRATION — BLUEPRINT
Date: 2026-11-04
Branch: feature/0.0.31-skse-single-dll-frontdoor

OBJECTIVE
Convert the existing 0.0.30 renderer into an SKSE-hosted single-DLL plugin for Steam Skyrim 1.7.104 / SKSE 2.3.1 while preserving all locked renderer behavior.

ARCHITECTURE
SkyrimSE.exe
  -> official SKSE 2.3.1
     -> Data/SKSE/Plugins/GZFX.dll
        -> SKSE preload/load + messaging/trampoline acquisition
        -> existing GZFX D3D11/DXGI renderer
        -> existing HLSL/GPU effects

IMPLEMENTATION
1. Add a minimal in-repo SKSE ABI declaration for the interfaces GZFX actually consumes. Do not redistribute SKSE runtime binaries.
2. Export SKSEPlugin_Version with exact initial compatibility for runtime 1.7.104.
3. Export SKSEPlugin_Preload:
   - reject editor/wrong runtime before modification;
   - arm the existing D3D11/DXGI import lifecycle probe early;
   - keep the plugin resident on the target runtime even if a later subsystem fails, because installed hooks must never point into an unloaded DLL.
4. Export SKSEPlugin_Load:
   - acquire plugin handle;
   - acquire Messaging and Trampoline interfaces;
   - register an SKSE lifecycle listener;
   - initialize the existing GZFX runtime;
   - record deterministic bridge status.
5. Move proven ExitProcess telemetry shutdown into GZFX.dll and make GZFX_Shutdown idempotent.
6. Remove dinput8 bootstrap dependency. Retain the existing Win32/raw-input menu path.
7. Remove d3d11 bootstrap dependency. Use SKSE preload + GZFX internal D3D lifecycle capture instead.
8. Build only GZFX.dll.
9. Package exactly Data/SKSE/Plugins/GZFX.dll.
10. Update CI to assert the exact one-DLL archive.
11. Replace proxy-specific tests with an SKSE front-door harness that emulates Preload -> Load -> D3D11 device/swapchain creation and proves primary attach.
12. Retain all renderer/math/semantic/telemetry tests not intrinsically tied to the retired proxy DLLs.
13. Preserve locked semantic source unchanged unless a compile-only integration adjustment is unavoidable.

NON-GOALS
- no CommonLib dependency;
- no new graphical feature;
- no WaterDomain/PostTonemapPreUi/AfterShadowProduction promotion;
- no claim of runtime support beyond 1.7.104;
- no ENB/ReShade coexistence work in this migration.

ACCEPTANCE
- Windows x64 build green;
- CTest green;
- SKSE exports/version contract green;
- emulated SKSE preload/load green;
- D3D11 primary attach after preload/load green;
- natural process-exit telemetry closure green;
- package contains one and only one DLL at Data/SKSE/Plugins/GZFX.dll;
- PR green before merge;
- merged-main green before field handoff.

END BLUEPRINT
