1. MISSION
======================================================================

Build runtime:

    0.0.25-late-stack-cartography-closure

Goal:

    close the remaining high-value late-renderer blind spots without starting
    another graphics-quality feature.

This wave must:

A. see inside Skyrim deferred D3D11 command lists by instrumenting the deferred
   contexts while they RECORD;

B. repair exact copy/resolve/clear resource lineage;

C. stop silently treating truncated concrete resource lists as complete;

D. promote field-supported HDR / tonemap-entry / global-TAA boundaries;

E. reduce detailed pipeline logging to the unresolved late renderer by default.

Do NOT tune AO.

Do NOT begin indirect radiance.

Do NOT replace TAA or tonemapping.

8. COMMAND LIST RECORD
======================================================================

At successful FinishCommandList:

create:

    CommandListRecord
    {
        uintptr_t commandListIdentity;
        uint64_t commandListGeneration;
        uintptr_t deferredContextIdentity;
        uint64_t deferredContextGeneration;
        uint64_t recordingGeneration;
        bool restoreDeferredContextState;
        bool complete;
        uint64_t originalPassCount;
        vector<PassRunTelemetry> runs;
    }

Registry key:

    commandListIdentity

but every record also carries a monotonic generation.

Replacing a reused pointer creates a new generation.

Live registry max:

    256 records

If capacity is exceeded:

    evict oldest record not currently being emitted;
    increment diagnostic eviction count.

======================================================================
9. FINISHCOMMANDLIST HOOK
======================================================================

Hook index 114.

Wrapper:

1. call original FinishCommandList;
2. on success:
   - seal current recorded runs;
   - assign list generation;
   - store registry record;
   - notify telemetry of list-seal metadata;
3. increment context recordingGeneration;
4. clear active run list;
5. if RestoreDeferredContextState == FALSE:
       reset tracked CurrentState to default;
   else:
       preserve state.

No file write.
