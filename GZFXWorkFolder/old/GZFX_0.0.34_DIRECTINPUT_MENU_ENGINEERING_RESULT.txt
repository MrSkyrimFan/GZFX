6. 0.0.34 IMPLEMENTATION
======================================================================

New internal one-DLL subsystem:
    include/gzfx/ui/directinput_mouse.hpp
    src/ui/directinput_mouse.cpp

No new packaged DLL was added.

Arm phase:
    normal SKSEPlugin_Load
    never SKSEPlugin_Preload

Runtime chain:
    GZFX.dll
      -> system dinput8.dll
      -> MinHook dinput8!DirectInput8Create
      -> real IDirectInput8::CreateDevice
      -> identify GUID_SysMouse
      -> hook real mouse IDirectInputDevice8::GetDeviceState
      -> hook real mouse IDirectInputDevice8::GetDeviceData
      -> forward mouse deltas/buttons to existing GZFX menu receiver
      -> suppress same physical mouse data from Skyrim only while GZFX menu open

Menu closed:
    exact input passthrough

Menu open:
    GZFX receives the physical mouse packet
    Skyrim receives zero immediate mouse movement/button state
    consumed buffered physical mouse events are suppressed

Safety guards:
    exact recorded system-mouse device pointer
    exact DIMOUSESTATE / DIMOUSESTATE2 immediate-state sizes
    unknown/non-mouse state remains passthrough
    non-mouse devices remain passthrough
    original HRESULTs preserved
