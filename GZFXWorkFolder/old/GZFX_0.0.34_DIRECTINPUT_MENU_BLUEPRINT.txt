======================================================================

        hook CreateDevice at the documented COM slot used by the historical
        field-working implementation

4. SYSTEM MOUSE IDENTIFICATION
======================================================================

HookCreateDevice:

    call original
    increment diagnostics

    only when:
        result success
        device non-null
        deviceGuid == GUID_SysMouse

    then:
        record exact returned system mouse interface pointer
        install mouse method hooks

No other input device is captured.

======================================================================
5. MOUSE DEVICE HOOKS
======================================================================

From the actual system mouse IDirectInputDevice8 vtable:

    GetDeviceState
    GetDeviceData

Store original functions.

Process lifetime ownership matches existing GZFX hook policy.

If a hook cannot be installed:
    fail closed for menu capture
    leave original input behavior untouched
    write exact diagnostic failure reason

======================================================================
6. IMMEDIATE STATE BEHAVIOR
======================================================================

HookGetDeviceState:

    call original first

If:
    original failed
    OR menu closed
    OR self != recorded system mouse device
then:
    return exact original result/data

If menu open and self is the system mouse:
    only parse exact known mouse-state sizes:
        sizeof(DIMOUSESTATE)
        sizeof(DIMOUSESTATE2)

Unknown size:
    passthrough unchanged
    never zero arbitrary buffers

Known state:
    decode lX/lY/lZ
    decode mouse button mask
    forward packet to:
        gzfx::ui::SubmitDirectInputMouse
    zero ONLY the validated mouse state buffer
    increment suppression counters
    return original HRESULT

This gives the GZFX menu the movement while Skyrim receives zero movement.

======================================================================
7. BUFFERED DATA BEHAVIOR
======================================================================

HookGetDeviceData:

    call original first

Passthrough if:
    original failed
    count pointer null
    menu closed
    self != recorded system mouse device
    DIGDD_PEEK set

For consumed system-mouse data while menu open:
    decode DIMOFS_X
    decode DIMOFS_Y
    decode DIMOFS_Z
    decode DIMOFS_BUTTON0..7
    maintain buffered button state

Avoid duplicate forwarding when a recent immediate-state packet already supplied
the same poll interval, preserving the previous field-working 8ms guard.

Then:
    set returned event count to zero
    preserve original HRESULT

Skyrim therefore does not receive buffered mouse events while the GZFX menu is
open.
