22. WHY A CONSTANT "EVERY SECOND" LISTENER IS NOT NEEDED NOW
======================================================================

The user authorized stronger instrumentation if current evidence was
insufficient.

Current evidence is sufficient.

Installing a high-frequency listener that continuously writes full renderer
state every second would now create:

- unnecessary disk traffic;
- large noisy logs;
- possible timing perturbation;
- harder evidence review;
- risk of confusing GZFX-owned work with the behavior being measured.

The better strategy remains:

    production system
    +
    bounded targeted probes inside it

If Wave 4 encounters a feature-specific unknown, add a targeted high-frequency
ring/listener for that exact signal.

Do not return to indiscriminate renderer archaeology merely because more data
can technically be collected.
