======================================================================
8. NATIVE MOTION CONTRACT
======================================================================

The locked convention is implemented exactly:

previousUV = currentUV + motion.xy

Native motion is consumed as:

R16G16_FLOAT
normalized logical screen-UV displacement

No negation.
No second Y flip.
No pixel conversion before history sampling.

Pixel-space magnitude is computed only for diagnostics/history-cap logic.

======================================================================
9. DYNAMIC RESOLUTION
======================================================================

The temporal shader uses:

current ratio:
DynamicResolutionParams1.xy

previous ratio:
DynamicResolutionParams1.zw

Current logical UV is mapped with the current ratio.

Previous logical UV is obtained from native motion:

previousLogicalUV =
currentLogicalUV + motion

Then previous history is sampled using:

previousDRUV =
previousRatio * previousLogicalUV

Current and previous ratios are not conflated.
