    a plausible early HDR downsample can begin the current reduction state

    HDRReduction and BeforeTonemap are falsely absent.

renderer contracts.

3. LANE A — BOUNDED HDR SOURCE SET
======================================================================

In FrameState replace the single mutable ancestry state:

    hdrReductionSourceIdentity
    hdrFullResAncestryDepth

with a fixed-capacity source collection.

Conceptual form:

    struct HdrFullResSource
    {
        uintptr_t identity;
        uint32_t depth;
    };

    static/fixed array capacity 4;
    source count.

Canonical MAIN_HDR remains implicit depth 0.

No heap allocation.

No eviction.

If capacity is full:
    fail closed on additional source.

Maximum ancestry depth remains:
    3.

======================================================================
4. LANE B — FULL-RES SOURCE DISCOVERY
======================================================================

While:

    lateStageEligible == true
    hdrReductionComplete == false

inspect every current RGBA16F Texture2D write.

If output is full screen:

    determine whether the pass reads:
        canonical MAIN_HDR
        OR a registered full-res source.

If yes:

    childDepth = parentDepth + 1;

    require childDepth <= 3;

    require output identity != parent identity;

    register output if not already present and capacity remains.

CRITICAL CHANGE:

    perform this discovery regardless of hdrReductionStep.

A full-res source observation does NOT automatically reset the active reduction
chain.

It only adds a verified possible root source.

======================================================================
5. LANE C — ROOT ELIGIBILITY
======================================================================

Create one bounded helper equivalent to:

    ReadsVerifiedHdrSourceLocked(mainHdr)

Return true when current pass reads:

    canonical MAIN_HDR
    OR any registered full-res HDR source.

Use it for:

    initial reduction root;
    fresh-root recovery after an incompatible/non-descending pass.

Do not use hashes or environment labels.

======================================================================
6. LANE D — REDUCTION CHAIN
======================================================================

Preserve the one active reduction candidate.

Initial root:

    RGBA16F Texture2D;
    <= half screen width/height;
    reads a verified HDR source.

Continuation:

    reads prior reduction identity;
    width <= prior width;
    height <= prior height;
    area strictly decreases.

If continuation fails:

    if current downsample reads any verified source:
        restart at step 1;
    otherwise:
        ignore.

Do not maintain multiple parallel reduction chains in this wave.

No evidence requires them.
