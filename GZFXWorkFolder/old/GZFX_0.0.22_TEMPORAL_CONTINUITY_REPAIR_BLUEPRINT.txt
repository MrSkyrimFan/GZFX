4. PING-PONG ACCEPTANCE
======================================================================

NORMAL_MASK_CURRENT is allowed to alternate physical backing identities every
frame.

If:

    current semantic is available
    descriptor contract is valid
    contractToken matches prior frame
    all other history continuity checks pass

then:

    history remains valid
    physical semantic generation change does NOT reset

The same principle applies to main depth and motion if their backing identity
changes while the semantic contract remains valid.

======================================================================
5. HARD RESET RULES
======================================================================

Retain hard reset for:

- first valid frame;
- frame gap;
- device generation;
- surface generation;
- dimensions;
- semantic contract change;
- camera generation;
- environment transition;
- runtime rebuild;
- missing input;
- execution failure;
- camera-cut flags from GPU continuity validation.

Physical semantic generation change alone is NOT a hard reset.

======================================================================
7. CAMERAZ BACKGROUND CORRECTION
======================================================================

Current invalid predicate:

    stockValid = finite && stockDepth > 0

Replace with:

    stockFar = max finite CameraZ mip0 sample

    epsilon =
        max(abs(stockFar) * 1e-5, 1e-4)

    stockBackground =
        abs(stockDepth - stockFar) <= epsilon

    stockGeometry =
        finite
        && stockDepth > 0
        && !stockBackground

Log:

    stock_far_value
    stock_background_pixels
    stock_geometry_pixels

Then compute:

    common_geometry
    gzfx_only_geometry
    stock_only_geometry
    both_background

using the corrected stockGeometry predicate.

Numerical error statistics are computed only over:

    gzfx geometry
    AND
    stock geometry

Keep the existing grayscale masks.

design, but the arm-then-act behavior is mandatory.
