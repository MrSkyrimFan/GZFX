2. AV2 — LIVE HORIZON SETTINGS
======================================================================

Add:
    #include "gzfx/settings.hpp"

Extend AV2 Parameters without changing existing field-proven defaults.

New submitted fields:
    horizonStrengthMultiplier
    horizonEnabled
    quality-derived slices
    quality-derived steps

Use settings snapshot at command recording time.

Horizon enabled:
    setting false:
        AV2 compute may skip for normal field execution
        stock AO remains untouched
    setting true:
        current AV2 path active

Horizon strength:
    setting default 0.25 must preserve current AV2 visual baseline.

    multiplier =
        clamp(setting / 0.25, 0.0, 4.0)

Pack shader:
    raw visibility = current AV2 result
    occlusion = 1 - raw visibility
    adjusted visibility =
        saturate(1 - occlusion * multiplier)

Mode 1:
    left remains stock
    right uses adjusted AV2

Mode 2:
    full uses adjusted AV2

Horizon radius:
    preserve current baseline:
        28 setting -> 240 RadiusWorld

    mapping:
        radiusWorld =
            clamp(
                240 * radiusPixels / 28,
                48,
                960)

Horizon quality:
    0 -> slices 2 / steps 4
    1 -> slices 3 / steps 4
    2 -> slices 3 / steps 6 [current baseline]
    3 -> slices 4 / steps 8

Quality therefore changes actual work.

AV2 status diagnostic must write:
    horizon_enabled
    horizon_strength_setting
    horizon_strength_multiplier
    horizon_radius_setting
    horizon_radius_world
    horizon_quality
    submitted_slices
    submitted_steps

3. LEGACY AMBIENT-DEPTH — INDIRECT-ONLY POLICY
======================================================================

Change public internal signature:

    ambient_depth::Apply(
        frame,
        device,
        context,
        inputs,
        allowAo)

Default/callers may retain allowAo=true where appropriate.

Inside Apply:

    effectiveAoEnabled =
        allowAo &&
        settings.horizonOcclusionEnabled

Early neutral skip becomes:
    if !effectiveAoEnabled &&
       !settings.indirectBounceEnabled
        -> skip_disabled

GPU parameters:
    aoEnabled = effectiveAoEnabled
    indirectEnabled = settings.indirectBounceEnabled

Do NOT alter existing:
    indirect strength
    indirect radius
    indirect saturation
    spatial/temporal stack behavior
    output composition

Under current AV2 modes:
    allowAo=false

This recovers SSIL without double-HBAO.

ambient_depth_stack.txt must record:
    ao_allowed
    ao_enabled
    indirect_enabled
    submitted values
    applications

4. SCENE EFFECTS — REMOVE THE GLOBAL AV2 BYPASS
======================================================================

Current bug:
    AV2 ownership causes immediate return before every scene effect.

Replace with:
    wave4OwnsAo =
        ambient_visibility_v2::OwnsDevelopmentMode(mode)

Keep mode 1/2 requirement.

Call:
    ambient_depth::Apply(
        ...,
        !wave4OwnsAo)

Then continue current scene-effects pass.

Result:
    AV2 owns Horizon/HBAO
    legacy stack contributes indirect only under AV2
    SceneEffects contributes AmbientContact + LocalGlow

Preserve:
    current source/depth/camera validation
    existing shader
    split/full development mode behavior
    fail-closed resource validation

pre_ui_effects.txt must no longer report:
    skipped_wave4_owns_mode

for an otherwise valid mode 1/2 frame.

It must report active/injection status and current settings.
