4. EXACT ROOT CAUSE — CURRENT MODE OWNERSHIP ORPHANED THE SETTINGS
======================================================================

Diagnostics/pre_ui_effects.txt is conclusive:

    status=skipped_wave4_owns_mode
    frame=3280
    injections=0
    mode=2
    ambient_contact_strength=2
    ambient_contact_radius=24
    local_glow_enabled=true
    local_glow_strength=1.375
    local_glow_threshold=0.25
    local_glow_radius=8

Current source:

    src/render/scene_effects.cpp

begins ApplyPreUi by asking:

    ambient_visibility_v2::OwnsDevelopmentMode(mode)

When true, it writes:

    skipped_wave4_owns_mode

and returns before:

    ambient_depth::Apply(...)
    settings-backed AmbientContact parameters
    settings-backed LocalGlow parameters
    scene-color effect injection

Current:

    ambient_visibility_v2::OwnsDevelopmentMode(mode)

returns true for development modes 1 and 2.

Those are the normal GZFX visual modes used in the field session.

Therefore:

    scene_effects is skipped in the modes where the user is testing GZFX.

This is why:

    AmbientContact settings do not reach scene_effects.
    LocalGlow settings do not reach scene_effects.
    ambient_depth::Apply is never reached through this path.
    HorizonOcclusion settings do not reach their legacy stack.
    IndirectBounce settings do not reach their legacy stack.

6. VISIBLE-PASS FALLBACK ALSO DOES NOT RESCUE THE SLIDERS
======================================================================

src/render/visible_pass.cpp does read:

    ambientContactStrength
    ambientContactRadiusPixels

but the shader only applies that fallback AmbientContact when:

    PreUiInjected == 0

The CPU sets PreUiInjected when either:

    scene_effects::WasInjectedFrame(frame)
    OR
    ambient_visibility_v2::WasAppliedFrame(frame)

GZFX2 shows AV2 applications succeeding.

Therefore the Present-time AmbientContact fallback is deliberately disabled on
the active AV2 frames.

Result:

    the old scene-effects settings path is skipped;
    the AV2 path is hard-coded;
    the visible-pass fallback is suppressed because AV2 succeeded.

The current effect sliders are consequently a disconnected control plane.
