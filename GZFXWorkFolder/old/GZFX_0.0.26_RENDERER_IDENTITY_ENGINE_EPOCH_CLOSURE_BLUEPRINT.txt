1. OBJECTIVE
======================================================================

0.0.26 is a renderer-identity and timeline closure wave.

It must convert the strongest scattered forensic capabilities already present
in GZFX into one coherent authority layer.

This wave does NOT add a new visual effect.

It must make the next real-Skyrim field run capable of answering, with stable
cross-run evidence:

    WHAT Skyrim engine epoch is active;
    WHICH stable shader programs are executing;
    WHICH resources they read/write;
    WHO owns every command list;
    WHEN work occurs relative to the actual DXGI Present.

Primary goal:

    close or decisively narrow the remaining late renderer map without another
    broad anonymous-D3D campaign.

======================================================================

        zero if unknown

    populate both fields.

8. LANE F — VERIFIED SKYRIM ENGINE EPOCH PROFILE
======================================================================

Implement a small standalone engine-epoch resolver inside GZFX.

No SKSE.
No Address Library runtime dependency.

Runtime gate:

    read live SkyrimSE.exe file/product version.

Initial supported engine-hook runtime:

    Steam Skyrim AE 1.6.1170.0

Any other version:

    do not install engine hooks;
    log unsupported/unverified runtime;
    continue D3D telemetry normally.

For 1.6.1170:

Scan executable .text for the verified exact signatures from Research Pass 9.

POST_PROCESSING signature:
    00 48 8B 0D 29 BD E5 01
    E8 04 32 FB FF
    48 8B 05 65 DF EB 01
    48 8B 88 28

CALL:
    match + 8

Expected target RVA:
    0x1481B80

PRE_UI signature:
    D2 48 8D 0D 46 37 2E 02
    E8 D1 F7 E9 FF
    48 8B 05 42 C1 64 02
    48 8B 48 10

CALL:
    match + 8

Expected target RVA:
    0xE44850

Acceptance before hook:

    exact version match;
    unique signature match;
    call opcode is E8;
    decoded target lies in executable image;
    decoded target RVA equals expected value;
    target is executable;
    target entry is not an unsupported existing redirection.

Install MinHook only after all validation for that anchor passes.

Each anchor is independent and fail-closed.
