======================================================================
5. RENDERER AUTHORITY / LOCK ORDER
======================================================================

CommonLib AUGMENTS GZFX renderer evidence.

It does not silently replace:

    D3D11/DXGI primary ownership
    renderer forensics
    shader/resource identity
    semantic freshness/fail-closed rules
    HDRReduction
    BeforeTonemap
    BeforeGlobalTAA
    AfterGlobalTAA

The bridge correlates CommonLib renderer COM identities with GZFX's existing
renderer_execution_service lease.

A first bridge draft risked an ABBA deadlock by holding the CommonLib state
mutex while entering renderer-forensics fallback attach, while Present could
take the same locks in reverse order.

Final lock rule:

    capture required CommonLib renderer pointers under CommonLib mutex
    release CommonLib mutex
    perform renderer-forensics fallback attach
    reacquire CommonLib mutex only to store/correlate result

Do not regress this ordering.
