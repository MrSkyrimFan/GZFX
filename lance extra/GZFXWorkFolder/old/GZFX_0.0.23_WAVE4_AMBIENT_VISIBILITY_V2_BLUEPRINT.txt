- no private Wave 3 pointer leaks.

Wave 4 must use this API rather than duplicate Wave 3 ownership.

======================================================================
13. GTAO NOISE
======================================================================

Use deterministic local procedural noise.

No external noise texture is required for the first production build.

Recommended:

    integer pixel hash
    +
    frame index
    ->
    two [0,1) values

Use for:

    slice rotation
    sample step jitter

Requirements:

- deterministic for a given frame/pixel;
- temporally varying;
- no visible fixed screen-aligned banding;
- no hue dependency.

Do not use a large random texture asset merely for noise.

======================================================================
14. SCREEN-SPACE RADIUS
======================================================================

Effect radius is world/view-space.

Derive approximate projected pixel radius from:

    RadiusWorld
    current view depth
    projection scale
    active render dimensions

Clamp to a practical maximum so extreme near-camera surfaces do not produce
unbounded sampling offsets.

Suggested initial clamp:

    ~1.5 px minimum
    ~512 px maximum

The hierarchy allows larger radii without linearly increasing local cache
pressure.

======================================================================
15. HORIZON SLICES
======================================================================

For each slice:

    phi =
        PI * (slice + sliceNoise) / SliceCount

Use opposite directions on the same slice.

Build:

    directionVec
    projected surface normal in the slice plane
    view vector
    two horizon values

This follows the GTAO paper's directional-slice model.

Do not use the old eight fixed screen directions.

======================================================================
16. SAMPLE DISTRIBUTION
======================================================================

For each step:

    normalizedStep =
        (step + jitter) / StepsPerSlice

Then:

    sampleFraction =
        pow(normalizedStep, SampleDistributionPower)

Add a minimum center-pixel exclusion.

For each side:

    sampleOffsetPixels =
        sampleFraction * projectedRadius * sliceDirection

Choose hierarchy mip from:

    log2(length(sampleOffsetPixels))

with a small mip bias.

Snap/align sampling sufficiently to avoid inconsistent direction/depth
locations.

======================================================================
17. SAMPLE VALIDATION / FALLOFF
======================================================================

For sampled positive view depth:

    reconstruct sample view position

Then:

    delta = samplePos - centerPos
    distance = length(delta)

Reject / fade when:

    invalid/background sample
    distance > RadiusWorld
    sample UV outside active logical render region

Falloff:

    full contribution through inner radius
    smooth fade over final FalloffFraction of RadiusWorld

Do not let far mountains occlude a nearby character merely because they are
within a huge screen-space kernel.

======================================================================
18. HORIZON INTEGRATION
======================================================================

For each side:

    sampleHorizonDirection =
        normalize(sampleDelta)

Compute horizon relation against:

    view vector

Retain strongest horizon along the side with falloff weighting.

Project native surface normal into the current slice plane.

Integrate the two horizons against that projected normal using the GTAO
paper's analytic visibility formulation.

Average over slice count.

Clamp:

    visibility = saturate(visibility)

Then:

    visibility =
        pow(visibility, VisibilityPower)

This stage is scalar geometry visibility.

No indirect color is added.

======================================================================
22. TEMPORAL SIGNAL HISTORY
======================================================================

Use Wave 3 geometry validation.

Inputs:

    SpatialVisibility current
    MOTION
    previous VisibilityHistory
    Wave3 geometryConfidence
    Wave3 reprojectionMask
    camera dynamic-resolution data

Rules:

1. compute:
       previousUV = currentUV + motion

2. previous dynamic-resolution mapping uses previous ratio.

3. reject if previous logical UV out of bounds.

4. require Wave3 reprojection accepted mask R > threshold.

5. sample previous visibility.

6. compute current 3x3 min/max from SpatialVisibility.

7. clamp previous visibility to current range.

8. derive temporal weight from:
       Wave3 confidence
       motion magnitude

9. blend:
       current/new signal
       clamped previous signal

10. write current VisibilityHistory.

If Wave 3 history invalid:

    temporal weight = 0
    current spatial signal becomes history.

Wave 4 does not reconstruct previous depth/world normals again.
