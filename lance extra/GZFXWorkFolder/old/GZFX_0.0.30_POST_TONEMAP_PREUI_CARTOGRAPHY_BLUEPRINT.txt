3. LANE A — EXTEND LATE DETAIL TO PHYSICAL PRESENT
======================================================================

Current telemetry behavior:

    detailed pipeline starts:
        AfterAmbientScreenSpaceComposite / AfterExecution

    detailed pipeline stops:
        UiPresent

Historical field/research evidence proved UiPresent is an internal semantic
marker and can precede additional GZFX callback work before the actual original
DXGI Present.

0.0.30 must change the late-detail cutoff to:

    PresentPhase::BeforeOriginalPresent

Exact behavior:

    at UiPresent:
        keep detailed pipeline active;
        do NOT disable the detail gate.

    at OnPresentTimeline(... BeforeOriginalPresent ...):
        flush pending pipeline pass;
        disable late detail when full-pipeline mode is not active;
        then enqueue the PresentTimeline event.

This guarantees all D3D work through Present callbacks is retained while still
avoiding the full-frame 0.0.24 telemetry firehose.

AfterOriginalPresent does not need detailed pipeline capture.

4. LANE B — 1.7.104 ENGINE-ANCHOR DISCOVERY ONLY
======================================================================

Current verified engine-hook profile:

    Skyrim 1.6.1170 only.

Do NOT weaken it.

Do NOT arm new engine hooks on 1.7.104 in this wave.

Instead add a discovery-only profile for:

    Skyrim 1.7.104.0

based on masked opcode skeletons derived from the already verified/publicly
corroborated callsite shapes.

The purpose is to discover candidate RVAs, not to claim semantic authority.

Post-processing skeleton:

    ?? 48 8B 0D ?? ?? ?? ??
    E8 ?? ?? ?? ??
    48 8B 05 ?? ?? ?? ??
    48 8B 88 28

Pre-UI skeleton:

    ?? 48 8D 0D ?? ?? ?? ??
    E8 ?? ?? ?? ??
    48 8B 05 ?? ?? ?? ??
    48 8B 48 10

Rules:

    - wildcard the leading byte and all relocation/call displacements;
    - require all fixed opcode bytes;
    - scan executable .text only;
    - count every masked match;
    - decode the direct CALL at match + 8;
    - require target inside main image and executable;
    - record a candidate only when exactly one valid match exists;
    - never hook the discovered candidate in 0.0.30;
    - never set engineProfileAvailable=true from discovery alone.

This is intentionally fail-closed.
