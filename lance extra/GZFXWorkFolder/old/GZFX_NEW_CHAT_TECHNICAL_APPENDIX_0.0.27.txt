======================================================================
REENTRANT INITIALIZATION
======================================================================

GZFX initialization state:

    0 not started
    1 initializing
    2 ready
    3 failed

This is required because dinput8 may load GZFX first.

During renderer_forensics target discovery GZFX creates a temporary WARP device.

That WARP request may enter local d3d11.dll.

If GZFX state=1:

    proxy forwards real D3D creation;
    does not recursively call GZFX_Initialize;
    does not attach WARP as primary.

Only state=2 may attach primary objects.

This avoids same-thread recursive std::call_once deadlock.

HDR DETECTOR
======================================================================

FrameState added:

    hdrReductionSourceIdentity
    hdrFullResAncestryDepth

Before reduction root:

    source = verified descendant if present
             else canonical MAIN_HDR.

Full-resolution ancestry candidate must:

    be RGBA16F
    equal screen resolution
    read current verified source
    be a different identity
    remain within depth < 3.

Reduction root may then consume that verified source.

Fresh-root recovery also uses the verified source.

Terminal now requires:

    hdrReductionStep >= 4
    width <= 2
    height <= 2.

Reason:

    hdr_reduction_complete_2x2_terminal

This encodes field structure, not field shader hashes.
