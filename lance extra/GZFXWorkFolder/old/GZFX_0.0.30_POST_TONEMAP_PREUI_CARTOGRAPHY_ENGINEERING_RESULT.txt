4. LATE-DETAIL BLIND SPOT CLOSED
======================================================================

Previous late-detail behavior:

    start:
        AfterAmbientScreenSpaceComposite / AfterExecution

    stop:
        internal UiPresent stage

Historical renderer evidence established that UiPresent is an internal semantic
marker and can precede additional Present-callback D3D work before the original
DXGI Present.

0.0.30 changes the cutoff to:

    PresentPhase::BeforeOriginalPresent

Behavior now:

    AfterAmbientScreenSpaceComposite / AfterExecution:
        start detailed late pipeline capture

    UiPresent:
        DOES NOT stop capture

    callbacks begin/end:
        capture remains eligible

    BeforeOriginalPresent:
        flush pending pass
        stop detail if not in full-pipeline mode

    AfterOriginalPresent:
        no second stop

Telemetry detail-gate reporting now identifies:

    late_to_before_original_present

This retains the previously hidden late interval without returning to full-frame
0.0.24 firehose logging.
