2. D3D11 RESOURCE-LINEAGE RESEARCH RECHECK
======================================================================

Microsoft documents shader-resource bindings as explicit state on the
ID3D11DeviceContext.

PSSetShaderResources:

    binds concrete shader-resource views to pixel-shader slots;

    if an overlapping resource is already bound for output, the destination SRV
    slot is filled with NULL.

OMSetRenderTargets:

    binds concrete render-target/depth output views;

    render-target views are explicit resources and current render targets can be
    explicitly unbound.

References:

    https://learn.microsoft.com/windows/win32/api/d3d11/nf-d3d11-id3d11devicecontext-pssetshaderresources

    https://learn.microsoft.com/windows/win32/api/d3d11/nf-d3d11-id3d11devicecontext-omsetrendertargets

Research consequence:

    resource identity + bound read/write state remains a truthful structural
    basis for the bounded HDR ancestry model;

    equal-size resources are still distinct resources and may be distinguished
    by identity even when width/height/format are identical.

Therefore the real field topology:

    640x360 false root
    ->
    640x360 real root from a different verified source

is valid structural evidence.

The test should model it exactly.

Current generic-depth tracking keeps per-frame collections of candidate

Reference:

    https://github.com/baldurk/renderdoc/blob/v1.x/renderdoc/driver/d3d11/d3d11_replay.h

3Dmigoto frame analysis records resources and explicitly tracks hash
contamination, reinforcing that hash identity alone is not sufficient renderer
authority.

Reference:

    https://github.com/bo3b/3Dmigoto/blob/master/DirectX11/FrameAnalysis.cpp

Independent architectural lesson:

    resource identity and frame-local candidate state are appropriate;
    exact shader hashes and magic draw ordinals are not required.

Nothing in the public research contradicts the current 0.0.29 source-set
design.

    create a separate equal-size field false-root target for the 0.0.29

        same dimensions as hdrReduceA
        different resource identity.

This avoids weakening or mutating the historical acceptance.

5. INTERVENING-WORK TEST DESIGN
======================================================================

Field observation:

    false root -> later full-res sibling
    gap = 26 ordinals on all 2,640 miss frames.

The number 26 must remain forensic evidence only.

It should NOT become:

    a constant;
    a timeout;
    a threshold;
    an acceptance count.

However, the synthetic test should prove the state survives unrelated same-frame
work.

Recommended approach:

    after the equal-size false root, execute a bounded sequence of unrelated
    non-RGBA16F draw operations;

    unbind their SRVs after each operation;

    then emit the later full-resolution HDR sibling;

    then emit the real equal-size root.

The filler count may mirror field scale for test realism, but no product or test
assertion should depend on its exact value.

The contract is:

    delayed same-frame sibling recovery works.

Not:

    sibling appears exactly N draws later.

7. CAPACITY CONTRACT RESEARCH
======================================================================

Current source:

    source capacity = 4;
    no eviction;
    additional source is rejected when full.

Field demand:

    max derived source count = 1.

The capacity is deliberately conservative.

A black-box acceptance can prove the behavior without test-only product hooks.

Synthetic topology:

    MAIN_HDR -> sibling 1
    MAIN_HDR -> sibling 2
    MAIN_HDR -> sibling 3
    MAIN_HDR -> sibling 4
    MAIN_HDR -> sibling 5

Then root a complete reduction chain only from sibling 5.

Expected:

    sibling 1-4 are admitted;
    sibling 5 is not admitted;
    reduction from sibling 5 does NOT signal HDRReduction/BeforeTonemap;
    TAA remains independent.

Companion positive sanity:

    chain from sibling 4 should be accepted.

This distinguishes:
    fixed capacity with no eviction

from:
    accidental capacity increase;
    eviction of an older source;
    arbitrary source admission.

9. FRAME-LOCAL ISOLATION RESEARCH
======================================================================

Current source places all HDR source candidates in FrameState.

EnsureFrameLocked() resets:

    g_frame = FrameState{}

whenever the physical semantic frame changes.

Therefore current source is frame-local.

To lock this against future drift, a black-box test should use a persistent
derived resource identity across two frames:

Frame A:
    establish:
        MAIN_HDR -> derived full-res source.

Frame B:
    do NOT re-establish that ancestry;
    attempt a complete reduction rooted only in the old derived resource.

Expected:

    frame-B HDRReduction absent;
    frame-B BeforeTonemap absent.

The test must still allow independent TAA detection.

This proves source identity persistence does not become semantic ancestry
persistence.
