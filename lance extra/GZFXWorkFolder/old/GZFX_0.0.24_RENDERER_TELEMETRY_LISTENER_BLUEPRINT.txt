======================================================================
1. MISSION
======================================================================

Build an XForge-style continuous forensic listener inside GZFX.dll so the user
can play Skyrim naturally while GZFX records the renderer session continuously.

Target runtime:

    0.0.24-renderer-telemetry-listener

Primary goal:

    discover Skyrim's full graphics pipeline and resource flow
    with minimal operator choreography.

The listener becomes the primary discovery instrument.

Manual capture remains optional visual evidence.

======================================================================
5. EVENT RING
======================================================================

Implement a preallocated lock-free MPSC bounded ring.

Capacity:

    262144 records

Each slot:

    sequence atomic
    fixed-size TelemetryEvent POD

Event record target:

    <= 128 bytes

No std::string
No std::vector
No heap allocation
No COM ownership

in the hot enqueue path.

If ring is full:

    drop record
    increment dropped count
    return immediately

Never block the render thread.

7. WRITER THREAD
======================================================================

Create one std::thread or Win32 thread owned by the listener.

Writer must NOT:

    call D3D11 immediate context
    call DXGI Present
    query live D3D state
    Map GPU resources
    resolve GPU queries
    call Skyrim renderer functions

Writer may:

    drain ring
    format text
    append CSV
    rotate files
    update health status
    maintain aggregate seconds.csv

Wake strategy:

    manual-reset/auto-reset event
    OR condition variable

Wake:

    when queue crosses threshold
    or
    every ~250 ms

Normal file-buffer flush:

    roughly once per second

No FlushFileBuffers per row.

10. PASS FAMILY SIGNATURE
======================================================================

Compute a 64-bit family signature from the compact pass state.

Adjacent passes are compressed if:

    signature identical
    pass kind identical
    same frame

Compression state stores:

    first ordinal
    last ordinal
    repeat count
    representative args

When signature changes:

    enqueue prior run
    begin new run

At Present:

    flush final pending run for the frame.

This keeps exact pass-family ordering without logging every repeated geometry
draw independently.

28. SESSION LIFECYCLE
======================================================================

runtime Initialize:

    initialize paths
    arm renderer hooks
    initialize Wave3
    initialize Wave4
    initialize telemetry listener

Telemetry listener stage callbacks can register before gameplay rendering
begins.

Renderer Forensics primary device attachment may happen later.

Listener remains active and begins frame/pipeline records once primary renderer
exists.

Shutdown:

    best-effort call from DLL detach
    set stop flag
    wake writer
    drain remaining queue
    write completion marker
    join with bounded safe shutdown path

Do not block indefinitely during process teardown.
