21. MAJOR BLIND SPOT:
SKYRIM DEFERRED COMMAND-LIST INTERNALS
======================================================================

Current continuous Pipeline Cartography records immediate-context work.

When Skyrim executes its own ID3D11CommandList, the listener records:

    frame
    ordinal
    command list identity
    restore-state behavior

but DOES NOT see the individual draws/dispatches recorded INSIDE that deferred
command list.

This occurred:

    9,487 times

during the session.

That is not a minor edge case.

It means the present listener still cannot claim:

    complete Skyrim renderer pass coverage.

This is now the primary architecture blind spot for full-stack discovery.

Future work will need to consider safe instrumentation of Skyrim-created
deferred D3D11 contexts / FinishCommandList content, not merely the immediate
ExecuteCommandList event.

No such implementation is started in DATA phase.

======================================================================
22. MAJOR LINEAGE BLIND SPOT:
COPY / RESOLVE / CLEAR OPERANDS
======================================================================

The compact continuous PassTelemetry currently captures rich bound-state
resource information for normal draw/dispatch work.

However, for operations such as:

    CopyResource
    CopySubresourceRegion
    ResolveSubresource
    ClearRenderTarget
    ClearDepthStencil
    ClearUAV

the compact event is currently emitted from bound pipeline state rather than
carrying the operation's explicit source/destination/view operands.

Result:

some resources that are known to be produced by copies or other explicit
operations appear as:

    read-only

inside the compact producer/consumer graph.

Examples include known copy-based semantic resources such as:

    DEPTH_EARLY_COPY
    PRE_WATER_DEPTH_CURRENT

This means:

    continuous resource lineage is strong for draw/dispatch bindings
    but incomplete for explicit copy/resolve/clear operations.

This must be repaired before calling the resource graph complete.
