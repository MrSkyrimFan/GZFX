6. IMPLEMENTED LANE B — SHADER CONTENT IDENTITY VS OBJECT IDENTITY
======================================================================

The old telemetry type error is removed.

Previously:

    shaderHashes[i]

could contain either:

    stable bytecode hash

OR:

    process-local shader COM identity/pointer.

That is no longer allowed.

PassTelemetry now carries separately:

    shaderHashes[6]
        stable exact bytecode hashes only
        zero when unknown

    shaderObjectIds[6]
        process-local canonical COM identities

    shaderHashKnownMask
        explicit stage-by-stage hash availability.

Immediate and deferred pipeline serialization now writes explicit columns:

    vs_hash ... cs_hash
    vs_object ... cs_object
    shader_hash_known_mask

Pass/run signatures use stable hash when known and object identity only as an
internal fallback for run compression.

Serialized evidence never pretends that fallback object identity is a hash.

This is the primary cross-run identity correction learned from the ENB /
3Dmigoto / Skyrim renderer research.

11. IMPLEMENTED LANE H — HDR/TAA DETECTOR REPAIR
======================================================================

HDR:

0.0.25 could commit to the first plausible MAIN_HDR RGBA16F downsample and then
remain poisoned for the rest of the frame.

0.0.26 can replace the current candidate when:

    the old chain cannot extend;
    a later pass is a fresh MAIN_HDR-descendant qualifying root.

The test harness deliberately emits:

    a smaller false MAIN_HDR reduction root

before:

    the real descending reduction chain.

Acceptance:

    detector abandons the false root;
    real chain reaches terminal HDRReduction;
    downstream late stages remain detectable.

Global TAA:

TAA structural recognition no longer requires:

    hdrReductionComplete
    or
    BeforeTonemap.

It independently recognizes the strong structure:

    MOTION
    + MAIN_DEPTH_CURRENT
    + >=2 full-resolution RGBA8 reads
    + exactly two full-resolution RGBA8 outputs.

Dedicated automated acceptance:

    global_taa_without_hdr_completion

PASS.

This prevents one upstream detector defect from blacking out downstream
temporal evidence.
