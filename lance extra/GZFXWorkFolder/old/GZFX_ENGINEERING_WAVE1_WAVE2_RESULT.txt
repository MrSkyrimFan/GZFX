A. SEMANTIC AUTHORITY LAYER

New files:

include/gzfx/render/semantic_authority.hpp
src/render/semantic_authority.cpp

Purpose:

Create a lightweight always-on semantic authority for the Skyrim renderer instead of requiring future effects to rediscover arbitrary textures by pointer, format, or timing guess.

The authority currently tracks/promotes structural semantic identities for:

MAIN_HDR
MAIN_DEPTH
MOTION
NORMAL_MASK_CURRENT
AUXILIARY_RT3
DEPTH_EARLY_COPY
OPAQUE_FINAL_DEPTH
CAMERAZ
SAO_RAWAO_CURRENT
SAO_RAWAO_PREVIOUS
SAO_FILTER_TEMP
SAO_FILTERED
RAW_INDIRECT
SHADOW_MASK
VOLUMETRIC_DENSITY_A
VOLUMETRIC_DENSITY_B
REDUCED_REFLECTION_LIGHTING [reserved / unresolved exact promotion]
REDUCED_TEMPORAL_LIGHTING_HISTORY [reserved / unresolved exact promotion]

Each semantic identity carries:

- confidence level
- canonical COM identity
- generation
- first-seen frame
- last-seen frame
- resource dimension
- width / height / depth
- mip count
- array size
- DXGI format
- bind flags

Confidence vocabulary:

Unknown
Provisional
Strong
Verified

The system deliberately leaves unresolved resources unresolved instead of assigning convenient names.

5.2 DEPTH CHRONOLOGY
------------------------------------------------------------

The authority distinguishes copies sourced from MAIN_DEPTH.

Before the main opaque MRT:
=> DEPTH_EARLY_COPY

First same-shape main-depth copy after opaque MRT activity:
=> OPAQUE_FINAL_DEPTH

The corresponding stage landmarks are emitted as:

after_depth_prepass
after_opaque_geometry_final_depth

This implements the blueprint rule that "depth" is not one timeless semantic object.

6. D3D11 STATE CORRECTNESS
============================================================

The Semantic Authority mirrors D3D11 read/output hazards.

When a resource becomes an output, matching stored SRV reads are nulled.

When an SRV is set while conflicting with an active output, the authority does not report it as a live read.

Reason:

D3D11 can automatically null incompatible read/output bindings.

Without this mirroring, GZFX could falsely infer a producer/consumer dependency from stale state.

This was explicitly hardened before merge.

8. ACTUAL D3D11 EXECUTION WIRING
============================================================

The Semantic Authority is wired into the real immediate-context hook path.

It observes:

- shader resources for VS / HS / DS / GS / PS / CS
- active shaders for all six stages
- render targets
- depth target
- graphics UAVs
- compute UAVs
- viewport
- draw calls
- dispatches
- CopyResource
- Present
- resize
- ClearState / command-list state reset

Important ordering:

BeginDraw / BeginDispatch:
before Skyrim's real D3D execution

EndDraw / EndDispatch:
after Skyrim's real D3D execution

AfterCopy:
after the real CopyResource call completes

This gives future stage callbacks meaningful before/after execution ownership.

============================================================
9. RESIZE / LIFECYCLE FIX
============================================================

During source audit a lifecycle problem was caught:

The initial scheduler Reset behavior would have erased registered callbacks after a ResizeBuffers event.

That was repaired before merge.

Current behavior:

resize invalidates renderer semantic/state data

BUT

registered stage subscribers survive resize

Explicit callback removal remains separate through ClearCallbacks.
