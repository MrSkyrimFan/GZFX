14. COMPACT LINEAGE LIMIT CHANGES HOW RESOURCE GRAPH MUST BE READ
======================================================================

The third-pass graph remains useful, but its interpretation must obey:

A. concrete read identities are capped at 8;
B. explicit operation rows may contain stale bound-state resource lists;
C. deferred command-list internals remain hidden;
D. full read/write hashes still detect complete binding-set changes.

Therefore resource status categories must be:

    VERIFIED PRODUCER
    VERIFIED CONSUMER
    PRODUCER NOT OBSERVED
    CONSUMER LIST TRUNCATED POSSIBLE
    DEFERRED-PRODUCER POSSIBLE
    EXPLICIT-OP PRODUCER POSSIBLE

not merely:

    read-only
    write-only.

This is a methodological correction for all future DATA passes.
