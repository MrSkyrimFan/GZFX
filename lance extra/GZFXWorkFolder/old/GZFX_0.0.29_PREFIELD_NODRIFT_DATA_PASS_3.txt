    height / 8

10. NEW DATA FINDING C — NEW HDR ACCEPTANCE IS PRESENCE-ONLY
======================================================================

Current wave3 pipeline harness reads stages.csv as one text string.

Positive late-stack acceptance currently asks only whether strings exist:

    hdr_reduction
    before_tonemap
    before_global_taa
    after_global_taa

somewhere in the complete synthetic session.

The harness executes its synthetic frame path approximately 35 times.

Therefore a regression where:

    one synthetic frame succeeds
    but many later synthetic frames fail

could still satisfy the current positive assertion.

This is weaker than the real field requirement:

    one HDRReduction per active scene frame;
    one BeforeTonemap per active scene frame;
    one BeforeGlobalTAA per active scene frame;
    one AfterGlobalTAA per active scene frame.

DATA classification:

    TEST ORACLE WEAKNESS = REAL

For no-drift closure the new HDR contract should use exact per-session/per-frame
counts, not substring existence.

    source capacity = 4
    max ancestry depth = 3
    no source eviction

    source set lives inside FrameState;
    FrameState resets on frame transition;
    capacity-full returns without eviction;
    parentDepth >= 3 rejects another descendant.
